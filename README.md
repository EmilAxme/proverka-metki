# Проверка скрытой метки

Страница читает невидимую метку TrustMark (вариант P) с номером свидетельства COPYTRUST.
Картинка не покидает браузер: декодер работает локально через onnxruntime-web.

Как устроено: центральный квадрат картинки сжимается до 224×224 так же, как в Pillow (BILINEAR),
декодер TrustMark выдаёт 100 бит, BCH_5 исправляет до 5 ошибок, контрольный символ отсекает шум.
Если сразу не нашлось, проверка пробует зеркало и центральные части 95–70 %.

- `model/decoder_P.onnx`: декодер TrustMark P, 8-битное сжатие весов
- `lib/`: исправление ошибок BCH из [adobe/trustmark](https://github.com/adobe/trustmark), MIT
- `ort/`: onnxruntime-web 1.20.1, MIT
